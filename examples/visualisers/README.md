# FrameRudiments Canvas gallery

Run from the repository root:

```sh
npm ci
npm run build
npm run demo:visualisers
```

Open <http://127.0.0.1:4195>. Use `PORT` to select another local port.

The gallery exposes all **222 visualisers**: 84 views accepting native movement
and 138 requiring calibrated spectrum/spectrogram data. The three music-aware
meshes can also use optional calibrated input. It starts with four native
movement views. The family selector lists the entire catalogue; the preset
buttons show paths, spectral histories, circular views, effects, wire meshes,
sprite atlases, solid meshes and music-aware meshes. The Sprite theme selector
offers all 17 original sheets. Music response selects native motion, calibrated
spectral deformation, or saved FFT terrain for `spatial-music-terrain`.
Select a native pattern, add a view and press the standard audio player's play
button. One-axis patterns cannot drive a paired-axis view. A gallery allows at
most 12 simultaneously mounted views.

No recording or sprite atlas is requested for the initial native views. The first spectral view
loads `/fixture.json`; subsequent views share the same request and native sample
table. Removing the last spectral view releases that recording. Adding a new
spectral view after release performs a new page-owned load.

The example hosts the built `lib/assets/visualiser-sprites/` directory and passes
its URL as `visualiserAssetBaseUrl`. Selecting a sprite view loads only its theme
PNG after SHA-256 verification. Views share the same atlas/grid within this page;
removing its last owner releases the decoded image and processed cells. Theme
metadata is available before any PNG request. Custom atlas setup is documented
in the [sprite guide](../../docs/rudiment-visualisers.md#sprite-and-atlas-visualisers).

Solid and music meshes use the CPU backend, including per-pixel depth, materials
and fog. Use a small number of simultaneous spatial views on slower devices;
`raster_size`, mesh density and fog/glow control their work. The default longest
raster edge is 512; extreme geometry can deterministically lower it further.
This page does not require WebGL, audio models or newly calculated FFT data.

The server reuses the [original synthetic fixture](../spectrum/fixture.mjs): an
eight-second generated tone plus separately hand-authored native Fourier-band
samples. The samples demonstrate the calibration/display contract; they are not
a measured StemLab FFT analysis of the tone. They are generated by the example
server, with an additional narrow band so peak-only views have a qualifying local
maximum. A smooth spectrum can correctly have no qualifying peaks. The samples
are never imported by the shared runtime or included in npm/WordPress
packages. The reusable PNG atlases are original FrameRudiments assets already
included in the build; no real song, model or downloaded media is needed.

The browser regression uses the same runnable example, exercises every renderer,
and checks native/calibrated inputs, source clocks, shared loads, responsive
Canvas output, accessibility preferences, seeks and teardown:

```sh
npm run test:visualisers:browser
```

`DANCEMOVES_BROWSER_EXECUTABLE` may point to a Chromium-compatible executable;
otherwise the installed Playwright Chromium is used. See the
[complete API and family styles](../../docs/rudiment-visualisers.md).
