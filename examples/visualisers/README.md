# FrameRudiments Canvas gallery

Run from the repository root:

```sh
npm ci
npm run build
npm run demo:visualisers
```

Open <http://127.0.0.1:4195>. Use `PORT` to select another local port.

The gallery exposes all **164 self-contained visualisers**: 58 native movement
views and 106 calibrated spectrum/spectrogram views. It starts with four native
movement views. The family selector lists the entire catalogue; the preset
buttons show paths, spectral histories, circular views, effects and wire meshes.
Select a native pattern, add a view and press the standard audio player's play
button. One-axis patterns cannot drive a paired-axis view. A gallery allows at
most 12 simultaneously mounted views.

No recording is requested for the initial native views. The first spectral view
loads `/fixture.json`; subsequent views share the same request and native sample
table. Removing the last spectral view releases that recording. Adding a new
spectral view after release performs a new page-owned load.

The server reuses the [original synthetic fixture](../spectrum/fixture.mjs): an
eight-second generated tone plus separately hand-authored native Fourier-band
samples. The samples demonstrate the calibration/display contract; they are not
a measured StemLab FFT analysis of the tone. They are generated by the example
server, with an additional narrow band so peak-only views have a qualifying local
maximum. A smooth spectrum can correctly have no qualifying peaks. The samples
are never imported by the shared runtime or included in npm/WordPress
packages. No real song, model, sprite atlas or downloaded media is needed.

The browser regression uses the same runnable example, exercises every renderer,
and checks native/calibrated inputs, source clocks, shared loads, responsive
Canvas output, accessibility preferences, seeks and teardown:

```sh
npm run test:visualisers:browser
```

`DANCEMOVES_BROWSER_EXECUTABLE` may point to a Chromium-compatible executable;
otherwise the installed Playwright Chromium is used. See the
[complete API and family styles](../../docs/rudiment-visualisers.md).
